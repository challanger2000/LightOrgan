# LightOrgan v1.0.0

LightOrgan is a retro-inspired Windows x64 VST3 audio-reactive visualizer with six frequency lamps and an optional white strobe.

## Features

- Six audio-reactive frequency lamps: Bass, Low, Low-Mid, Mid, High-Mid, High
- Modes: ORGAN / BOTH / STROBE
- Controls: Sensitivity, Decay, Brightness, Strobe Threshold
- UI sizes: 68% and 100%
- Mechanical MODE-button click generated by the editor/UI only
- Audio is analyzed for visualization and passed through unchanged
- Strobe rate safety-limited to a maximum of 8 flashes per second

## Installation

Copy the complete `LightOrgan.vst3` bundle to:

`C:\Program Files\Common Files\VST3`

Restart or rescan plug-ins in your DAW. Load LightOrgan as an audio effect, for example on an individual channel or the master/output bus.

## Photosensitivity warning

LightOrgan contains flashing and stroboscopic visual effects. Flashing lights may trigger seizures or other adverse reactions in people with photosensitive epilepsy or other photosensitivities. If you know that you are photosensitive, do not use the strobe function.
