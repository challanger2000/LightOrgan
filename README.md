# LightOrgan

A retro-inspired VST3 light organ with six audio-reactive lamps and strobe visualization for music production and playback.

## Initial concept

- 6 frequency-reactive lamps: Sub, Bass, Low Mid, Mid, High Mid, High
- Strobe mode for strong transients
- Modes: Organ / Both / Strobe
- Controls: Sensitivity, Decay, Brightness, Strobe Threshold
- Audio is analyzed and passed through unchanged
- Windows VST3 target
